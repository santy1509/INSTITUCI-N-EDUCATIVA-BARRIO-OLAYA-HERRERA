ACTUALIZACIÓN DE ESTA VERSIÓN
1. Haz una copia de seguridad de tu proyecto actual.
2. Para aplicar las mejoras de la tabla, reemplaza estos cuatro archivos:
   - app.js
   - almacenamiento.js
   - index.html
   - estilos.css
3. Conserva tu firebase-config.js y tus reglas actuales de Firestore.
   Esta mejora no necesita publicar reglas nuevas ni cambiar la configuración de Firebase.
4. Sube los cambios a GitHub y espera a que GitHub Pages actualice la página.

INSTALACIÓN INICIAL (solo si todavía no has configurado Firebase)
1. En Firebase Console > Firestore Database > Rules, configura las reglas incluidas.
2. En Firebase Console > Authentication > Users, localiza la cuenta que será el administrador principal.
3. Copia el UID de esa cuenta. En Firestore > Data, crea la colección `usuarios`.
4. Dentro de `usuarios`, crea un documento cuyo ID sea exactamente el UID copiado.
5. Añade estos campos:
   - nombre: texto, por ejemplo "Administrador principal"
   - correo: texto, el correo de esa cuenta
   - rol: texto, valor exacto "admin"
   - activo: booleano, valor true
8. Inicia sesión en la página con esa cuenta.
9. Desde Usuarios autorizados, crea las cuentas de profesores y otros administradores.
10. Prueba primero con datos ficticios antes de cargar información real.

IMPORTANTE SOBRE LA PRIMERA CUENTA
La primera cuenta administradora se autoriza manualmente desde Firebase Console.
No se permite que cualquier persona cree su propio perfil de administrador desde la
página. Después de crear ese primer documento, los administradores pueden crear
perfiles adicionales desde la aplicación.

MIGRACIÓN
- Al iniciar sesión como administrador, el sistema intenta copiar estudiantes,
  llegadas y avisos del almacenamiento local antiguo a Firestore, sin sobrescribir
  documentos que ya existan.
- Las cuentas antiguas guardadas localmente no se convierten en cuentas Firebase.
  Deben crearse desde Usuarios autorizados.
- El sistema no elimina los datos antiguos del navegador.

PERMISOS
- Administradores: gestionar usuarios y estudiantes, importar, exportar/restaurar
  copias y borrar el historial.
- Profesores: consultar estudiantes, registrar llegadas, consultar historial/avisos
  y marcar avisos como atendidos.
- Las reglas de Firestore también protegen estas operaciones; ocultar botones no
  es la única medida de seguridad.

NOTA
La creación de usuarios adicionales utiliza una app secundaria de Firebase para
no cerrar la sesión del administrador que los está creando. Desactivar un perfil
bloquea el acceso a la aplicación; no elimina la cuenta de Authentication.

MEJORAS DE ESTA ACTUALIZACIÓN
- Se retiraron los botones y la apertura automática de WhatsApp.
- La tabla agrupa registros con el mismo nombre para mostrar al estudiante una sola vez.
